# Entornos de Desarrollo (EDE)

Materiales del módulo **0487 Entornos de Desarrollo**, primer curso de **Desarrollo de Aplicaciones Multiplataforma (DAM)** y **Desarrollo de Aplicaciones Web (DAW)**, modalidad **semipresencial**, curso **2026/27**.

El módulo recorre el desarrollo del software de extremo a extremo: lenguajes y fases de construcción, instalación y configuración de entornos integrados, depuración, control de versiones y colaboración con Git y GitHub, diseño de pruebas y pruebas automáticas, refactorización, análisis y documentación de código, y modelado UML de clases y de comportamiento.

## Entorno de trabajo

- Aules como aula virtual
- **IntelliJ IDEA** como IDE principal y un segundo IDE (VS Code u otro);
- terminal; 
- **Git, GitHub y GitHub CLI**, con GitHub Actions cuando la práctica lo requiera; 
- **JUnit 5**, depurador del IDE, analizadores como SonarLint y dobles de prueba con Mockito; 
- **UML** con diagrams.net, PlantUML o Mermaid.

Las herramientas y lenguajes concretos son elecciones del curso. En este sentido apostaremos por **Java** y **Kotlin** como lenguajes principales de programación, por ser más coherentes con stack empleado en el resto de los módulos y por su ecosistema de herramientas y bibliotecas. Se podrán hacer algunas menciones puntuales a **Python** y **JavaScript**. No obstante, los materiales se redactan de forma que puedan adaptarse a otros lenguajes y entornos.
